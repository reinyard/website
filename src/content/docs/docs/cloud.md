---
title: Managed cloud
description: The hosted version of Reinyard, coming soon.
---

A managed cloud (SaaS) is planned for teams that would rather not run Reinyard themselves. It is the same platform, operated by us, and runs use Google sandboxes.

Enterprise will be offered as SaaS, on-premises or hybrid, with single sign-on, SCIM provisioning, audit logs, SIEM integration, delegated admin roles, metrics and alerting, and support with an SLA.

It is **not available yet**, and pricing will be announced at launch.

To hear when it opens, write to [contact@reinyard.com](mailto:contact@reinyard.com).
